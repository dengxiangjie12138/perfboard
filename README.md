## 软件更新与发布

从 `0.1.1` 起，“版本与说明”提供手动检查及可选的自动检查更新。从 `0.1.3` 起可选择 GitHub 或 Gitee 国内镜像，默认 GitHub，记住本机选择；历史版本下载与更新检查统一使用所选来源。首次需手动安装支持更新的版本；后续由用户主动下载并保存、重启安装。签名密钥、发布资产生成与验证步骤见 [软件更新与发布说明](docs/UPDATES-AND-RELEASES.md)。

GitHub → Gitee 的代码与发布文件自动镜像、首次配置和无令牌验证见 [Gitee 镜像说明](docs/GITEE-MIRROR.md)。

## GitHub 数据备份与恢复

当前数据库内容随源码保存在 [data/current](data/current/)，包括物料、笔记、开发日志及其中的图片和附件，并保存当前本机设置数据库。SQLite 文件通过只读连接导出一致性快照，不上传运行中的 WAL/SHM 文件或历史数据库备份。恢复方法和快照更新命令见 [备份与恢复说明](docs/BACKUP-RESTORE.md)。

当前快照以 `data/current/manifest.json` 的时间、文件哈希和表记录数为准；后续使用产生的数据不会自动同步到 GitHub，需要重新导出并提交推送。
