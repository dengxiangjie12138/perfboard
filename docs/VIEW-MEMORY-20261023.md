## 保存边界

`viewMemory.ts` 和 `useViewMemory.ts` 提供带版本标识的本地存储，按窗口、功能及需要时的仓库路径分组。Windows 普通路径、大小写/分隔符差异及长路径前缀统一处理，主窗口和独立窗口不会互相覆盖。界面记忆保存在本机 WebView 配置，不随仓库备份迁移到其他电脑。

通用状态钩子在操作时写入，初次读取不会用默认值覆盖坏记录或未来版本。新增字段采用默认值；枚举、导航目标、画布视角、进制和制作单缓存有读取校验。无法读取时页面可继续打开；变压器编辑现场实际写入失败时提示先保存仓库记录。单条缓存上限 2 MiB，仍受本机 WebView 的存储配额约束。

滚动位置在帧内合并保存，并加入已有导航/关闭保存屏障；延迟载入的正文与图片可在尺寸就绪后恢复位置，用户开始操作后停止自动定位。没有新增数据库表、仓库迁移、网络请求或依赖。
