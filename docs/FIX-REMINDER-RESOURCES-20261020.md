# 2026-10-20 提醒响应与图片缩放修复

版本保持 0.1.0。本轮针对关闭/开始无响应、多套提醒窗口混杂、资源卡片常驻说明和图片不可调大小四项反馈。

## 行为

- 久坐与健身统一在一个活动提醒容器；升级沿用同一窗口，副显示器只有遮罩及退出入口。
- 开始运动后在原容器显示“运动进行中”，用户完成后再确认。关闭/Esc 仍是稍后处理，不误记完成。
- 退出先处理可见窗口及内存状态，不等待数据库成功；存储错误保留在状态中，不能被周期推送抹去。
- 图片单击选中后显示等比例缩放手柄，方向键可微调，Esc 取消当前拖动，提供“重置大小”。
- 图片 `displayWidth` 为可空整数（64–4096 px），只影响显示，前后端共同验证；旧文档不要求增加此字段，原图数据不改写。
- 图片和附件卡片不再显示常驻副本说明。“打开”tooltip 说明临时副本及外部修改不自动回写。

## 备份与数据保护

开始前确认用户程序已经退出，备份位于 `.quality/reminder-resource-fix-20261020/backups`；`backup-manifest.json` 记录源码压缩包、旧程序、配置和仓库数据库的 SHA-256。

已有 `src/features/core-library/CoreLibraryPage.tsx` 修改和 `PRD/standing-reminder-preview.html` 保留。本轮使用新的隔离配置、仓库、WebView 档案和 QA 标识，不更改用户计时偏好。
