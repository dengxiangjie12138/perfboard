# 开发日志整行折叠响应修复 — 2026-10-22

用户验收 PDF、文件夹和拖动等功能通过，指出项目行、文件夹行折叠比箭头迟缓。本轮只调整这两种行的点击处理，并同步“版本与说明”，版本仍为 0.1.0。

## 原因与行为

原实现为区分单击与双击，将整行单击延迟 300 毫秒；箭头直接更新状态。快速点击不同的行时，共用的等待任务还会取消前一次点击。

现在第一次点击立即更新折叠状态，不设置等待任务；浏览器识别到第二次点击属于双击时，恢复第一次点击前的折叠状态，再进入原有改名流程。双击期间第一次点击仍会即时改变展开状态，第二次点击恢复；改名、取消或确认后的展开状态与双击前一致。右侧新建、菜单、箭头和改名输入框不触发行点击。

快速点击不同文件夹时，每次更新均保留；折叠不会保存草稿或切换当前页。文件夹归属、排序、PDF 导出和数据库结构沿用上轮已通过验收的实现。
