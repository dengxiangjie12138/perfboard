# 分压计算器（2026-10-22）

硬件计算选型新增独立分压工具，模块位于 `src/tools/voltage-divider/`。输入供电电压 Vin、上电阻 R1、下电阻 R2，阻值支持 Ω、kΩ、MΩ。数字和单位改变后立即更新，保留现有应用主题、卡片、分式与上下标排版，支持搜索和独立窗口，无需连接仓库。

按中点无外接负载的理想直流模型计算：

- 中点电压：Vmid = Vin × R2 / (R1 + R2)。
- 串联电流：I = Vin / (R1 + R2)，R1 与 R2 的电流相同。
- 默认 5 V、10 kΩ、10 kΩ，结果为 2.5 V、250 µA。
- 支持 0 V，以及其中一颗电阻为 0 Ω；两颗同时为 0 Ω 显示短路错误。
- 空白、负数、非有限值和结果超出数值范围时，清除旧结果并明确提示。仅支持非负供电。
