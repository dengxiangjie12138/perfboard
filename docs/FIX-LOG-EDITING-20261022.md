# 日志多行样式与文件夹删除

2026-10-22，版本仍为0.1.0。本轮只修改开发日志编辑和文件夹操作，保留原有运放计算等功能。

跨段落选中文字后，可一次设置标题、无序/有序/任务列表、引用或代码块。操作后继续保留完整选区，可接着设置加粗、文字颜色和对齐。向前选、反向选、全选、仅有光标的原有单段操作均已检查。

原来的四类格式辅助函数把普通TextSelection强制改为锚点所在块的NodeSelection，格式化后又把光标移到段尾，因此只能改第一块。现在使用对应的原生Tiptap命令，让ProseMirror映射完整选区。没有改动上游原版文件和许可证；运行时适配说明已更新。

文件夹右键新增“删除文件夹”。确认框说明其中页面会移回项目根目录，正文、附件和历史版本保留。原本已在回收站的页面仍在回收站。页面按文件夹内顺序占据原文件夹在根层的位置。当前页有草稿时先完成保存/放弃/取消流程；取消和写入失败不删除文件夹。

后端检查项目状态、文件夹修订号和项目内跨窗口编辑占用；删除容器、清除归属和调整排序在一个事务内完成。陈旧确认和已删除项目均拒绝操作，排序写入失败完整回滚。不修改数据库schema版本，本次仍为v6。
