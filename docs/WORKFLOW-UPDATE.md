# Perfboard 0.1.0 工作流更新

本批更新窗口保存、搜索、物料布局、仓库工具记录、设置和开发日志。源码/离线快照保留在项目中，版本仍为0.1.0。久坐提醒方案是独立讨论文档，未实现为应用模块。

## 使用与保存

左侧物料、笔记分类、日志、磁芯库和工具入口右键选择“在独立窗口中打开”。每次打开创建新窗口；相同计算器的输入互不影响。JSON原文按主窗/子窗编号存于本机 WebView 草稿存储，关闭后重新使用空闲编号可恢复该编号的原文；其余计算器重新打开从默认输入开始。WebView 草稿不是仓库备份的一部分。

同一笔记或日志仅有一个窗口可写，其他窗口明确只读。原窗口保存后切换文档或关闭，另一个窗口点击尝试编辑会重新读取最新内容。后台版本检查拒绝旧版本保存；当前草稿和保存入口保留，不能覆盖新内容。关闭失败、退出失败或备份前保存失败保持窗口并显示原因。

主窗隐藏到托盘不关闭其他窗口；整应用退出等待全部窗口完成保存。仓库切换与手工/自动备份使用相同屏障，保存期间冻结交互，切换完成后窗口重新读取当前仓库。子窗只有对应内容权限，不允许任意窗口创建或修改其他领域设置。

## 开发日志

真实官方免费 MIT Simple Editor，来源 commit `799929bea4804c73767562b69f8acc2acdb8ac86`，完整许可与原始文件见 `third_party/tiptap-simple-editor/`。采用官方免费 FindAndReplace，前景色是 Color/TextStyle 加本地颜色面板；未使用付费 ColorTextPopover。

右侧树管理项目与页面，可通过加号、右键和拖动操作。正文自动保存；“保存”也可主动刷写。回收站恢复页面或项目；项目恢复仅恢复随该项目删除的页面，原先单独删除的页面维持删除状态。页面历史可恢复内容；撤销栈按页面隔离。

任务复选框、无序/编号列表及 Enter 延续使用编辑器实际节点。Ctrl+F 只查当前页面。左侧独立槽显示段落、标题、代码块与列表项的逻辑序号；软换行不新增序号，序号不进入复制选择或 JSON。此版不提供图片上传或云协作。

日志以结构化JSON+schemaVersion1+revision存于 SQLite 的 dev_log_projects/dev_log_pages/dev_log_page_history，拒绝未知结构/不支持的版本，保存冲突保留草稿。Excalidraw 笔记继续使用原结构和原始 sceneJson，不转换为日志。

## 搜索与物料

侧栏搜索固定于品牌下方/工作空间标题上方，导航列表单独滚动。顶部与侧栏使用同一规则，任一时刻只有一个结果弹层。全部精确/pinyin/AND结果在前；Fuse.js7.5.0只补充单独标明的近似建议。数字、封装、料号、型号与物理m/M不参与近似放宽。

物料移除重复介绍，搜索与筛选独占一行。页面不跟列表滚动；列表内部滚动，列名表头固定。详情、新建/编辑、附件与原存储逻辑保留。

## 仓库、外部工具与迁移

数据库徽标度量 perfboard.sqlite3 本体的实际文件字节，WAL与本地附件字节单列；不展示虚构百分比，失败显示无法读取。

外部工具记录跟随 SQLite 仓库，不依赖安装目录。缺失或路径无效的记录保留，可搜索定位并重新选择绝对本机 EXE。只在用户点击启动时运行；不自动安装、删除记录或嵌入 EXE 窗口。旧全局 external-tools.json 可安全导入唯一仓库；原文件保留，仓库身份/导入凭据避免重复导入。

首次打开v1/v2仓库，先在线备份完整SQLite和登记的本地附件到仓库backups/pre-migration-vX-to-v3-*。备份校验成功后单事务新增笔记revision及日志/外部工具表，升级user_version3；失败回滚。原笔记 JSON 字节保持不变，重复打开不再迁移。v3不向旧应用伪装为v2；回退应恢复完整迁移前目录。测试未访问任何真实用户仓库。

## 自动备份与登录启动

默认关闭。用户选择已存在本机父目录和HH:mm后保存设置；应用或系统托盘运行时执行，当天到点后启动只尝试当天。一进程一个调度器，日期尝试记录随仓库持久化，重启/时钟回拨也不重复当天。

自动备份写入所选父目录内 `.perfboard-auto-<warehouseUUID>`。先完成在线数据库快照和登记附件复制，核对SQLite、附件字节及每个软件自有文件SHA256，并写验证清单，再保留最近5份已验证自动备份。手工备份及未知文件、目录、重定向/junction、内容被替换的旧备份保留；遇异常显示清理警告并跳过清理。新备份失败保留全部旧备份。当日保存屏障失败记为失败，当日不再自动重试。不会在应用退出后后台运行。

软件设置保留主题和关闭行为；Windows登录启动只有主动勾选并保存才改系统注册。注册参数--autostart使主窗初始隐藏、托盘可用；托盘创建失败则显示主窗。测试用内存适配器和隔离启动参数，实际启动项前后哈希一致。
