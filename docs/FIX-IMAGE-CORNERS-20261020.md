# 图片四角缩放修复（2026-10-20 实现，2026-10-21 交付）

版本保持 0.1.0。本次仅改进开发日志图片缩放；既有提醒修复、附件功能和用户原有修改保留。

## 使用与布局

- 单击选中可编辑图片后显示细选择边框与四角控制点；取消选中或只读时隐藏。
- 控制点为 7px，透明命中区域通常为 28px；小图片的每个命中区不超过图片对应尺寸的一半，避免上下角互相遮挡。
- 左上、右下使用 `nwse-resize` 光标，右上、左下使用 `nesw-resize` 光标。没有原先突兀的单个右下角按钮底框。
- 拖动超过 3px 后锁定主要方向，横向位移直接调整宽度，纵向按原比例换算；Esc 取消。手柄点击和双击不打开图片，拖动结束后短暂抑制意外双击。
- 图片仍在富文本正常文档流内，从原有左上位置排布；四角控制尺寸，不承诺对角固定或自由移动图片。
- 显示宽度保存为 64–4096px 内的整数，并受编辑区宽度约束。保存关闭重开保留宽度；原图资源 BLOB 不改写。
