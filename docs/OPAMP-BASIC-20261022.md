## 计算与建模边界

反相与求和使用带符号的信号增益，带宽使用噪声增益。直流图可绘制负斜率；求和扫描 Vi1 时固定 Vi2，差分与仪表扫描 Vdiff 时固定 Vcm。

双运放仪表的通用节点解为：

`Va = Vi1 + (R3/R4)(Vi1−Vref) + (R3/Rg)(Vi1−Vi2)`

`Vout = Vi2 + (R2/R1)(Vi2−Va) + (R2/Rg)(Vi2−Vi1)`

三运放输入级分别求解 Va/Vb，再通过输出级两节点求解。R5、R6 可独立变化；不要求两者相等，也不把不匹配的输出级套进减法简式。共模、差模和基准增益从通用系数求得。两种仪表拓扑均检查内部输出及各运放输入共模范围，避免最终输出正常却掩盖内部饱和。匹配按钮只计算 R4，不暗中改动其他电阻。带宽只显示 GBW/最大级内噪声增益的单级估算，明确不代表整机 −3 dB 带宽。

积分器采用 `H(s)=−(R2/R1)/(1+sR2C1)`；微分器采用 `H(s)=−sR2C1/[(1+sR1C1)(1+sR2Cf)]`。Cf 为 0 时去掉其滤波因子。计算实际 RC 幅相、直流中心、输出峰值幅度、极点、时间常数和近似单位增益频率；图示三个正弦稳态周期。

积分器原图的失调补偿、微分器的分压与去耦网络简化为理想可调 Vref，页面明确说明，未假装计入失调或寄生。电源旁路元件不参与信号计算。曲线不包含有限开环增益、压摆率、上电、初始电荷和饱和恢复；用 GBW、RC 极点、输出包络提示适用条件。限幅仅为范围示意，不是 SPICE 仿真。
