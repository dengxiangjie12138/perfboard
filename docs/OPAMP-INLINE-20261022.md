# 运放图上编辑与公式排版 — 2026-10-22

版本仍为 0.1.0，入口仍为“硬件计算选型 → 运放选型计算”。本轮在首次集成基础上实现用户的四项反馈；按最终第 4 点直接取消右侧参数栏。用户明确表示已退出应用并授权修改、更新。

## 交互

- 双击电阻、Vin/Vi1/Vi2、Vref、Vcc/Vee 的图形或标注打开就地编辑；键盘 Tab 定位、Enter/空格也可打开。打开后数值自动聚焦并选中，可直接键入。
- 数值和电阻单位变化后立即更新结果、数值代入和曲线。Enter、“完成”或点击空白结束编辑；Esc 或 × 撤销本次编辑，同时恢复该参数原来的数值和单位，不恢复其他参数。
- 单击仍可选择参数，点击空白或 Esc 解除高亮。无效值在编辑器和原理图标红，暂停结果、公式和曲线；关闭编辑器后仍可从错误提示重新打开该参数。
- 原理图直接显示正负供电及其当前值，双击修改。H、GBW 放在图内右上角，示例操作和差分匹配按钮放在左上角；窄窗口中这些操作排列在图内顶部以免遮挡拓扑。
- 原电路选择、三种主题、中文 TI 参考、搜索和会话草稿继续保留。四电阻差分仍使用通用公式，仅显式匹配按钮才修改 R4。

## 公式

使用原生 MathML 排版符号和数值代入，电阻比值显示为横线分式，变量带上下标，括号随分式高度伸缩；同相输出展示 `Vout = Vin × (1 + R1/R2)`。差分节点电压、失配分解、CMRR、噪声增益和带宽使用相同格式。每行保留可访问的线性公式说明。

计算算法没有改动，数学排版使用同一计算结果；无效参数时仍清除计算过程。依照 [Chromium 原生 MathML 支持说明](https://developer.chrome.com/blog/new-in-chrome-109/) 使用 WebView2/浏览器内置排版，无新增外部脚本、字体或 npm 依赖。
