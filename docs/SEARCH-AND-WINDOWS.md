# Perfboard 0.1.0 搜索、窗口与草稿规则

记录：2026-10-03。

## 搜索契约

空白分词按AND组合，顺序不限，每个词可命中同一记录的不同字段。仓库搜索覆盖型号、分类、封装、品牌、商城编号、旧参数、位置与简介；全局再覆盖页面/工具、笔记标题/分类/已保存画布文字及外部应用名称/介绍。外部程序路径不参与搜索，结果只定位记录，仍由用户点击启动。

中文通过本地pinyin-pro 3.29.4生成无声调全拼与首字母别名，原文匹配优先于全拼、全拼优先于首字母；相同得分保持输入顺序。中英文数字混合词使用连续拼音匹配且保持汉字及数字约束。普通英文、拼音、k/K和型号大小写不敏感；已识别物理量前缀m/M保持区别，例如1mΩ与1MΩ、mA与MA、IEC写法4m7与4M7。搜索不做单位换算。

数字片段需守住相邻数字边界，不做编辑距离或数字错字纠正：100k不会命中1100k，0603不会被0604替代，603不会自动补零变为0603。字母型号仍支持连续子串。每次先检索完整已提交snapshot，再应用预览数量上限；仓库显示全部匹配行。变更字段或换仓后缓存更新，未保存的物料/笔记草稿不进入搜索。

当前约1918条记录采用缓存别名和确定性匹配即可，不额外维护全文数据库。以后若数据规模明显增长，可评估MiniSearch等索引方案，同时保留上述AND、数字、m/M和同步契约；本批未加入模糊搜索服务。

## 工具窗口契约

共用受控清单：feedback、timer、radix、led、resistor-series、resistor-parallel、json、wire-gauge。Rust验证工具ID、固定标签和本地路由，拒绝URL、路径、笔记和外部工具ID；子窗无通用创建窗口或启动外部程序权限。独立宿主只呈现工具及回到主窗/关闭操作，不复制完整侧栏。

同工具重复打开复用现有子窗并激活，保留当下输入；不同工具、主窗与子窗的输入结果独立。关闭计算器子窗后重开恢复初始输入；JSON采用以下持久草稿策略。仓库和主题共享，成功仓库变更由Rust广播、所有窗口重读同一数据库。LED仍需要已连接仓库，其余工具沿用已有仓库门槛。笔记并发编辑和外部EXE嵌入未加入。

关闭子窗等待该窗保存，仅销毁自身。主窗默认关闭隐藏到托盘，子窗继续工作；改为退出或点击保存并退出时，收集主窗及全部子窗的当前保存结果。任意失败取消退出、显示错误窗口，旧请求或错误标签的确认不能完成新请求。

## JSON原文草稿

本机WebView localStorage按稳定窗口标签及工具ID保存版本化封装：perfboard.draft.v1.main.json与perfboard.draft.v1.tool-json.json。封装中的raw是原字符串，不经过JSON数值解析，非法或未完成原文、大整数、空白均保留。每次编辑即时保存；刷新、子窗关闭重开及正常整应用退出后启动分别恢复。主窗/子窗不共享JSON输入。

读取损坏或存储写入失败时保留错误和当前原文，不静默覆盖旧字节；关闭/退出被阻止。用户显式修改或清空后重新保存可建立有效草稿。工具草稿属于本机应用配置，不进入SQLite、仓库附件或仓库备份；移动仓库不迁移WebView配置。

## 证据与离线预览

47项相关前端用例、8项Rust协调/路由用例、66次实际隔离原生断言和45次PRD浏览器断言通过。原生覆盖主/子输入隔离、工具复用、共享仓库增改删、主题UI同步、JSON刷新/重开/完整重启、保存失败阻止退出、子窗关闭和主窗托盘隐藏。

当时的搜索与多窗口快照使用98个冻结的生产文件，以独立浏览器适配器提供1918条合成内存物料及浏览器子窗演示；与实际Windows关闭/托盘/权限验收分开。演示草稿使用独立perfboard.prd.search-windows-20261003命名空间，不读写实际应用草稿、用户仓库、系统剪贴板或外部EXE。旧快照已按用户要求于 2026-10-27 清理，验证事实继续保留，范围见VALIDATION.md。
