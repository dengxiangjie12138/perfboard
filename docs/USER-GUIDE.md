# 洞洞板 / Perfboard 0.1.0 使用说明

## 2026-10-07 新增用法

工具 → 硬件选型计算 → **变压器设计记录**。新建后选择磁芯与骨架，分别记录逻辑绕组、绕线/绝缘工序、材料、测试、附图和说明。设计保存到当前仓库；导入旧 JSON/XLSX 时先预览，再逐项确认。历史表的未知单位、绕向、同名端和分组保留待确认，不自动当作 0。查看示例不代表审核通过，导出的示例 PDF 带“仅示例 / 未审核 / 不可生产”标记；交付打样前应逐项确认。选用磁芯时，系列参考图与来源一起冻结到记录中。

物料页“全部状态”后有 **显示立创仓库**。默认不选并记住选择；不选时只在该页隐藏位置等于“立创仓库”的条目，其他检索和电阻候选照常使用全部库存。

久坐提醒从休息恢复工作，需要连续 5 秒的非明确注入 Windows 活动，活动间隔不超过 1 秒。偶然触碰一次不会恢复，确认期间仍计为休息；既有工作/休息时长保留。该输入过滤不认证真人或虚拟 HID 来源。

新版首次打开旧仓库会先生成完整迁移前备份，再升级为 v4。继续使用原仓库路径；本轮没有把现有设计表批量写入你的仓库。更多范围及验证状态见 [本轮说明](FIVE-GROUP-UPDATE-20261007.md)。


## 安装与开始

当前更新提供直接EXE，固定入口为 deliverables/Perfboard-0.1.0/perfboard.exe；2026-10-03新构建需先手工合并准备目录。保存并退出旧程序后替换安装位置的同名EXE，原仓库继续使用。以下安装器说明为历史行为，当前没有匹配最新功能的安装包。运行历史小在线安装包时，依次选择程序目录和数据仓库目录。安装器额外提供仓库页面：可以创建空仓库，也可以明确选择复用已有 Perfboard 仓库。两个目录必须互不包含，不能选择磁盘根目录、未知非空目录或目录联接。应用使用当前用户安装。

历史小在线安装包 `Perfboard_0.1.0_x64-online-setup.exe`：先检测 WebView2，缺少时联网下载并安装。已安装运行时的电脑可使用直接 EXE。原约 223 MiB 离线包包含旧功能，保留为历史备用产物，本批未重打。安装包未进行代码签名。

第一次打开是空仓库。主界面左下角显示连接状态和实际仓库路径。找不到原仓库时，应用进入“恢复仓库连接”，不会自动生成另一个空数据库。到“仓库与数据”重新选择已有位置；需要新仓库时，明确点击“初始化所选目录”。

## 物料仓库

“添加物料”可记录型号、封装、分类、品牌、立创商城编号、位置、库存状态和简介。型号必填，可填 0Ω 或 STM32F103C8T6；品牌和商城编号可留空，编号按文本保存字母与前导零。型号和封装独立显示，不再重复输入参数。位置可检索已有位置，输入 0 可匹配 0805电阻盒，也可录入新位置，保存后可再次选择。数量可留空，只有需要精确数量时才填写。数量为 0 会保留。库存状态是日常查找的提示，软件不实现采购或 ERP。

简介是可留空的多行文字。点击一行展开，每一行独立展开或收起；可就地编辑、保存或取消。详情中可以修改完整物料，也可以添加本地图片、PDF 和网页链接。导入附件会复制到仓库的 `attachments`，不会移动原文件；删除附件只处理自己的副本。删除物料移除记录和附件关联，当前实现保留失去关联的副本文件，不自动清理未知文件。

分类、库存状态和搜索可组合筛选。工作台及顶部搜索使用当前仓库中已经保存的物料、笔记标题和画布文字，点击结果打开对应记录。

## 搜索与独立工具窗口

搜索用空格组合条件，每个词都必须命中同一条记录的某个字段，词序不限。例如 `100k 0603`、`0603 100K`；`dianzu` 可匹配电阻，`dzh` 可匹配电阻盒。普通英文和型号忽略大小写，mA/MA、mΩ/MΩ等物理量仍有区别。数字和封装不做错字模糊匹配；`603` 不自动等同 `0603`，搜索不自动换算单位。

在支持的工具页面点击顶栏“独立窗口”，可并行使用反馈电阻、定时器、进制转换、LED限流、串联、并联、JSON解析和线径。每种工具同一时间只开一个子窗口，重复点击显示已有窗口。输入和计算结果各自独立；仓库新增、修改、删除及主题变化会同步到其他窗口。关闭子窗只关闭它，主窗隐藏到托盘后子窗继续工作，整应用用“保存并退出”。

JSON原文按主窗口和JSON工具窗口分别即时保存，未完成或无效JSON也会保留，刷新/重开/程序重启后恢复。其他计算器子窗关闭重开会恢复初始输入。工具草稿保存在本机WebView配置，不属于SQLite仓库或完整备份；界面提示草稿保存失败时，修复存储问题后重试，关闭/退出会等待保存成功。

## 笔记

“笔记概览”保留介绍与完整笔记本列表。分类固定为“硬件错题本、软件错题本、随笔、学习笔记”；分类页移除介绍和宽列表面板，使用紧凑选择器切换已有笔记、按新建创建当前分类笔记，画布扩展。新建后使用原版 Excalidraw 编辑文字、图形、电路草图和图片。场景元素、画布状态和图片文件一起保存到 SQLite；本地自包含 SVG 也可恢复。

修改后自动保存；“保存”可立即提交。离开页面、切换仓库、隐藏窗口或退出前会等待保存。写入失败会保留当前草稿和窗口，显示错误；排除故障后点击“重试保存”。不要在保存失败时强制结束进程。

“导出”得到带图片的 `.excalidraw` JSON，可用于恢复和迁移；编辑器左上角原版菜单也可导出图片。“导入”会替换当前画布。涉及外部嵌入或不安全图片时先提示过滤数量，只有明确确认才应用；取消保持原笔记。

已有场景如果无法完整、安全地恢复，会阻止编辑和覆盖，并提供“导出原始 JSON”。这样可以保留原数据，供检查和恢复。不要删除这类笔记来尝试修复。

## 工具与外观

反馈电阻按 Vout、Vref、误差上限和最大分压电流计算。电流硬上限默认 0.1 mA，可修改，必须为有限正数。E24 / E96 和库存候选统一筛选，并显示实际 Vout、标称误差、电流及上下电阻功耗。I = Vref / Rbottom，P = I²R；无合格候选时保持空结果。库存优先读取型号中的明确阻值，兼容历史参数；不会把封装数字当阻值。显示层将舍入噪声归零，算法仍按原精度比较。结果需核对芯片规格书、反馈偏置电流、阻值范围、稳定性和容差约束。

STM32 定时器计算需要填写实际定时器输入时钟 `Ftim`，软件不会代替具体芯片的 RCC 时钟树推导。按 16/32 位 ARR、目标频率或周期求 PSC / ARR，显示实际频率、周期和误差；也支持手动参数。

“外观”提供浅色、深色、Codex 深色，默认 Codex；选择保存在当前仓库。关闭窗口默认隐藏到系统托盘，可在外观设置改成退出。托盘支持显示、隐藏、保存并退出；再次打开程序会显示已运行窗口。

## 完整备份、迁移与恢复

到“仓库与数据”点击“选择位置并备份”，指定一个新的备份目录。软件先保存当前编辑，再使用 SQLite 在线备份 API 生成一致数据库，并复制有记录关联的附件及清单。无需关闭应用，也不要在应用运行时手动只复制数据库主文件。

恢复时，保留当前仓库和备份原件，在“仓库与数据”打开备份目录，或先把完整备份复制到一个新的最终目录再打开。路径配置保存在 `%APPDATA%\com.perfboard.toolbox\repository.json`，业务数据不放在该配置目录。

仓库的主要内容是 `perfboard.sqlite3`、`attachments` 和 `backups` 目录；完整迁移应整体移动，并在应用中重新选择位置。手工移动前先保存并退出。卸载程序保留仓库、附件和路径配置，复装时可以复用原仓库。

所有业务功能使用本地数据。点击自己保存的网页链接会交给系统浏览器访问对应网址。

## 本批更新与旧数据

版本仍为 0.1.0，用交付目录和 Git 提交区分构建。更新前可在原应用做完整备份，然后从托盘“保存并退出”，替换安装目录里的同名 EXE。第一次用新程序打开 v1 仓库会在事务中兼容升级到 v2，品牌和商城编号默认为空，不同于型号的旧参数保留到简介，原兼容字段仍保留。重复打开不会再次追加。v2 仓库应使用本批或更新程序，原历史程序不支持 v2。仓库位置、笔记和附件继续保留。
