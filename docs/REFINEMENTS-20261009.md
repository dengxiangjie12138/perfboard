## 已完成

1. 工作与健身显示“今日累计活动”，按本机本地日期换日。旧 totalActiveMs 全期累计保留，新增默认兼容的 dailyActiveMs / dailyActiveDay；旧状态没有日期，首次升级今日从 0 开始，不把全期数值当作今日。午夜只清零当天累计，activeMs、待处理提醒、稍后剩余时间、动作池和处理历史保留。
2. 活动量仍来自原单调钟输入区间。最多两个不连续活动区间分别裁剪到当天，连续跨午夜、空闲尾段、读取状态夹在两次采样之间均精确处理。墙钟紧接输入采样捕获，在日志写盘之前配对；停机/睡眠/大间隔不补算，墙钟异常跳变不把不确定区间加入今日。启动、换日、状态读取和退出保存前归一日期，换日及时持久化。原文损坏时仍禁止自动写回；日归一保存失败显示今日 0、停用累计并在释放状态锁后收起提示。
3. 健身历史及久坐每日分段使用同一局部滚动容器，高度按表头及前 20 行实际尺寸计算，窗口宽度和长名称变化时重算。全部记录保留，表头固定，可键盘滚动；既有最近 200 条健身历史保留规则不变。
4. 两处主启用控件使用原生 checkbox、switch 语义和滑动外观，开启绿色、关闭灰色，保留 Tab、空格和焦点。颜色使用既有主题变量；久坐即时保存，请求中禁用防重复；健身保留“保存设置后生效”的既有草稿语义，失败保留草稿。
5. 制作单基本信息新增自由输入骨架描述，兼容旧字段缺失、null、空值，最大 4000 字符；保存重开保留，预览及中文 PDF 换行打印。旧骨架快照不推定为新文字，schemaVersion 仍为 1，没有仓库迁移。预览位于编辑区下方；工具栏顺序为结束编辑、导出 PDF、预览。预览只滚动，不保存、不结束编辑、不丢草稿。移除 JSON/SVG 导出入口，原导入和完整旧记录 PDF 保留。
6. 删除主界面多余说明页脚与专属留白，关于页只保留日期。三主题与主/独立窗口容器继续使用现有全局样式。
