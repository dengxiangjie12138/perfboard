## 保存与拖放

自动保存从首个未保存编辑开始计 60 秒，继续输入不推迟；保存使用服务端版本号，写入途中编辑仍由串行保存队列处理。关闭开关会取消待执行计时并保留草稿；重新开启从当时起计 60 秒。开关保存在本机 WebView 配置，同源窗口同步；不会更改仓库结构。

自动保存关闭时，切页、创建页及涉及草稿的操作需明确选择保存 / 放弃 / 取消。原生关闭、退出、切换仓库、备份的跨窗口保存屏障不能在冻结界面中等待交互：它们先取消操作并保持窗口，显示处理草稿的对话框；处理后重新操作。失败不丢弃草稿。

主窗包含动态切换的日志与笔记，需要 HTML 拖放。独立窗仅开发日志及 Excalidraw 笔记关闭 Tauri 原生拖放处理器；其余工具保留默认。当前 JSON 页没有显式的第一方文件拖入入口，其树编辑器不提供上游文本模式切换；附件通过本地选择框导入；源码无 Tauri 原生文件拖入事件消费者。Excalidraw 通过 HTML `dataTransfer.files` 处理图片。官方依据：[Tauri 配置](https://v2.tauri.app/reference/config/#dragdropenabled)。

## 久坐提醒规则

- 默认关闭；用户启用后工作 45 分钟 / 连续休息 3 分钟 / 无操作确认 60 秒。键盘或鼠标活动都算工作，只读取当前 Windows 会话最后活动时间。
- 无操作确认期算工作，首次确认后才开始连续休息，不回溯休息。默认自然离开约 4 分钟可清零；主动“开始休息”立即开始 3 分钟。短休保留工作累计，零碎休息不相加，恰好达到阈值先结算再响应输入。
- 实际观察到的锁屏 / 睡眠算连续休息，达到休息阈值后在可信恢复事件中结算清零（离开期间可显示休息剩余为零）；会议暂停冻结工作、休息和稍后计时，不算休息。没有可信系统事件的异常时间差、程序关闭期间不算已验证休息；恢复不补过期锁屏。
- 单个 Rust 服务拥有计时及提示权限，与仓库连接无关；多个主 / 独立窗口只订阅同一状态。设置与工作累计保存在独立配置目录的 `standing-reminder.sqlite`；正常退出保存最后累计，硬崩溃最多损失最近约 30 秒工作计时。
- 三个时长在下一轮生效；功能、声音与自动锁屏开关立即生效。小提示窗提供“开始休息 / 稍后 5 分钟 / 收起”，本轮稍后一次，收起 60 秒后最多再提醒两次；收起不清零工作。
- 自动锁屏默认关闭；只有提示窗已显示并确认渲染后才开始 15 秒预警。可以取消，收起仍计时。休息、暂停、稍后或关闭开关取消未发出的请求，每轮最多请求一次，失败显示错误不循环重试。Windows 接受请求不等于已完成锁屏，休息由系统会话事件确认。
- 提示使用不激活窗口的显示方式；静音仍显示文字。普通全屏可以显示，独占全屏 / 安全桌面无法保证覆盖。

系统接口依据：[最后活动时间及非递增限制](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)、[异步锁屏请求与会话通知](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-lockworkstation)、[睡眠 / 恢复通知](https://learn.microsoft.com/en-us/windows/win32/power/wm-powerbroadcast)。
