# 开发日志三项改进（0.1.0，2026-10-04）

基于用户已验收的十二项更新提交 b658be4fe15b11d333f5128e1ac68dfe82cdc56a。本轮只改开发日志的改名、回收站和上次选择，不升级版本，不迁移仓库结构。

1. 标题平时显示文字，仅双击标题文字范围进入改名。项目和页面树整行双击改名，单击选择或打开。Enter 立即保存，Esc 或失去焦点取消；空白名称保留编辑并报错。IME 合成中的 Enter 不提交。输入框复用共享组件，业务保存与拖动规则在日志功能目录。
2. 回收站支持单个项目/页面永久删除和清空。确认框展示项目、页面数量、对象及不可撤销提示；默认焦点在取消，只有主动确认才执行。确认范围在打开时冻结；其他窗口恢复、新增垃圾、修改相关历史或切换仓库后，旧确认失败且没有部分删除，需要主动刷新并重新确认。项目删除在同一事务移除全部已删除关联页面及历史，包括先于项目删除的页面；活动记录和共享附件文件保留。
3. 原生配置目录的独立 view-state.sqlite3 只记录项目和页面 ID，按规范仓库路径、功能、窗口编号隔离。主窗和独立日志窗口分别记忆，副窗不会改主窗记录；只读浏览不写记忆。明确指定的独立窗口页面/项目优先，否则恢复本窗口上次选择。页面不存在或已删时保留有效项目的列表，项目也不存在时显示项目列表，不自动打开无关页面；新仓库没有记忆时从项目列表开始。正文草稿由原编辑器管理，不写入选择存储。

点击不同项目会在处理现有草稿后回到该项目列表；同项目单击展开，箭头单独折叠。拖动期间及结束后 500ms 内抑制改名，编辑名称时禁止开始拖动。
