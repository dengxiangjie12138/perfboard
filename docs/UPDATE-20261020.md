# 2026-10-20 提醒升级与开发日志资源

版本维持 0.1.0。本次保留 Tiptap 与既有仓库，不迁移物料模块的外部附件。

## 使用方式

- 健身和久坐仍先显示原来的小提醒。未处理超过设置的等待时间后，显示跨显示器半透明遮罩和中央操作面板。默认等待 5 分钟，可在提醒设置中调整或关闭升级。
- 大提醒中可开始休息/运动、稍后或跳过；开始运动不等于已完成。Esc 或关闭会解除遮罩并稍后提醒。两类提醒同时到期合并处理，锁屏或休眠不累计补弹。
- 开发日志支持插入图片、Ctrl+V 粘贴截图/图片及拖入图片。普通文件可通过插入按钮或拖入添加，显示原文件名、大小、打开和另存为。
- 单个资源最大 20 MiB。支持预览 PNG、JPEG、GIF 和 WebP；超出可预览尺寸或不支持的图像格式可以作为普通附件保留。普通文件字节保持原样。
- 导入操作会保存已有正文、资源和插入后的页面。导入期间请等待完成；保存失败会显示错误并保留草稿。
- “打开”交给系统默认程序查看隔离临时副本，外部修改不会自动回写日志。需要编辑副本时请另存；需要更新日志文件时重新导入。

## 保存、历史与迁移

图片和普通文件共用 SQLite 的 `dev_log_resources` 表，正文及历史只保存资源 ID。资源内容不可变；跨页粘贴复制资源归属，永久删除来源页不会损坏目标页。

正文移除资源时保留原字节供历史恢复；进回收站仍保留，永久删除所属页面时一并删除。资源不进入页面列表快照，图片按需读取。

仓库结构从 v4 升级为 v5。升级前沿用完整备份，再事务迁移；旧数据保持。新增日志资源随数据库一致备份带走。现有物料外部附件仍需随完整仓库迁移，不能在程序运行时只复制主数据库文件。
