# 工具计算规则与数据边界

当前八项为进制转换、LED限流、电阻串联、电阻并联、JSON解析、独立磁芯参数库、线径计算、通用外部工具。应用版本保持0.1.0。工具下包含硬件计算选型、STM32计算、常用小工具三个同级折叠组，整行切换展开状态；磁芯参数库独立位于工作空间。

## 固定位宽整数

默认32位无符号，可选8/16/32/64位以及有符号/无符号。同一位模式切换符号模式只改变十进制解释。二、八、十六进制显示位宽内的补码位模式；二进制补足位宽，八/十六进制补足对应长度。所有整数值使用BigInt，不能经Number转换。

十进制无符号范围0至2^w−1；有符号−2^(w−1)至2^(w−1)−1。非十进制正输入表示0至2^w−1的位模式；有符号负输入转换为补码。允许对应0b/0o/0x前缀。空输入、单独符号和仅前缀为未完成态，非法字符、浮点和超范围为错误；原始输入保留，运算/复制不能把错误默认为0。

A为工作值，B为二元操作数。AND/OR/XOR/NOT及左移结果保留低w位；逻辑右移补0，算术右移始终按最高位复制符号位，与十进制显示模式无关。移位只接受0至w的整数：移w位时左移/逻辑右移为0，算术右移为全0或全1。位号从0（最低位）至w−1（最高位），点击翻转A对应位。宽化时无符号补0、有符号符号扩展；窄化保留低位，数值发生变化时明确提示截断。

## LED限流

输入供电Vs、单颗正向压降Vf、目标电流If(mA)、串联LED颗数N（默认1），必须为有限合法值，N为正整数且Vs>N×Vf，If>0。只适用于串联，不能用于并联LED共用电阻。理论R=(Vs−N×Vf)/(If/1000)，理论耗散P=(Vs−N×Vf)×If/1000。

候选来自复用现有E24/E96系列（本期10Ω至1MΩ）或真实库存解析器；同阻值的不同物料记录保持独立，显示位置和封装。默认只推荐阻值不小于理论值且标称电流不大于目标的候选。每项实际If=(Vs−N×Vf)/R，P=(Vs−N×Vf)^2/R，没有可用值时明确说明。

额定功率建议按默认2倍经验裕量（可调）向上选择常见档位。库存功率只能从明确的阻值规格尾缀或额定功率字段文字提取有单位数值，矛盾、缺失和不明确均为未知；不按封装猜功率。已知足够的库存元件优先显示实际封装；不足/未知明确区分。标准值封装参考采用Vishay D/CRCW e3系列70°C标准模式，0402 0.063W、0603 0.10W、0805 0.125W、1206 0.25W、1210 0.5W、2010 0.75W、2512 1W。该表只作具体系列参考，不能代替库存料号规格和温度降额。[厂家资料（修订2026-04-14）](https://www.vishay.com/docs/20035/dcrcwe3.pdf)，页1技术规格、页2标准/扩展模式区分。

结果是标称Vf简化模型。Vf随温度与电流变化，供电和电阻容差影响实际最大电流；功率裕量并不保证绝对不超流或热安全，高功率LED宜考虑恒流驱动。

## 串联与并联额定功率限制

各入口独立，共享底层算法及表单。默认两个电阻，支持新增/删除；每项阻值可选Ω/kΩ/MΩ及正额定功率W。提供共用单颗额定功率与批量应用，允许逐项覆盖。

串联Req=ΣRi；Imax=min√(Pi/Ri)；Pgroup=Imax²×Req。并联Req=1/Σ(1/Ri)；Vmax=min√(Pi×Ri)；Pgroup=Vmax²/Req。统一结果显示等效阻值、整组额定功率限制和限制元件。等值、同功率电阻可得到额定功率相加；不同阻值受最先达到额定功率的元件限制，不能无条件相加。

Ri、Pi须为有限正数。空、非法、零欧和超出可表示范围不产生NaN、无穷或假零结果；零欧需要实际短路参数，本期不支持。结果只按理想额定功率计算，不是实际耗散或耐压保证；热耦合、温度降额、最大工作电压与实际安装条件需另外核对。本期不增加供电、混联或自动库存组合。

## JSON解析

左侧保留原文，右侧使用本地 vanilla-jsoneditor 3.13.0（ISC），通过 lossless-json 4.3.1（MIT）解析与回写，避免超过 JavaScript 安全整数范围的数据精度损失。提供格式化、压缩、转义、反转义、压缩并转义、复制、搜索定位、折叠及分层展开。反转义只接受完整 JSON 字符串；格式化与压缩只处理有效 JSON。

输入未完成或无效时保留原文并暂停树形编辑，不自动修复覆盖。树形解析上限256 Ki字符，展开一次最多3层，较深结构逐层展开。全部处理在本机，无外部上传、CDN或嵌入网页。

## 磁芯参数库

这是参考参数库，与库存物料独立。原始来源为用户桌面文件 副本CoreList.xls，Sheet1，137条记录，14个类别；源文件SHA256为 DE64AB3AC56801EB8B9601416727837B53AE9B11B969B3E222A60799750F688F。导入器保存原字段值、单位、空值、来源行号和工作表信息，生成随应用分发的只读JSON。源Excel与库存数据库不改写。

15列：TYPE、MATERIAL、Dimensions(mm)、Ap(cm4)、Ae(mm2)、Aw(mm2)、AL(nH/N2)、Le(mm)、Ve(mm3)、Wt(g)、PCL、Pt、BOBBIN幅宽、PIN、形状。页面直接显示紧凑筛选、列表和详情，移除常驻介绍及说明块；型号与原字段搜索、类别和材质筛选、完整详情继续保留。原表未注明BOBBIN幅宽单位，页面明确显示未注明，不能假定为mm。没有厂家列，不能从材料名推断厂家。

PCL注明100kHz、200mT、100℃及W；Pt只注明100kHz、Watts，没有完整磁通与温度条件，不能视为通用变压器额定功率。PCL缺18条，Pt缺91条，幅宽缺50条，PIN缺55条，形状缺51条。空值保持空值。本期不增加反激计算、材料曲线、库存数量或推测参数。

## 通用外部工具

每条记录包含稳定ID、自定义工具名称、本机EXE完整路径和必填应用介绍，支持新增、编辑和删除。配置文件external-tools.json保存在应用配置目录，与库存/笔记仓库无关；未打开仓库时，工作台与外部工具页仍可使用。删除只移除记录，不删除第三方程序或其依赖目录。

独立ExternalToolsProvider保存完整记录列表；全局搜索和工作台按名称与介绍匹配，不按路径检索、不截取前几条。保存、改名、修改介绍或删除成功后重新读取并通知两处搜索。结果使用externalToolId定位对应记录，物料/笔记ID保持独立；缺失或已删除的选择只显示提示，不触发启动。

用户点击记录中的启动按钮后，后端再次按ID读取配置并核查路径；仅直接启动选定EXE，工作目录为其所在目录，不传参数、不使用shell。拒绝相对路径、URL、UNC网络路径、脚本、附加命令参数和缺失文件；不要求固定程序文件名。已有记录路径失效时仍保留介绍及状态，启动不可用，用户可编辑恢复。EXE路径合法不表示供应商身份或签名认证。

旧配置中显式保存的superconnectx_path读取为一条SuperConnectX记录，空路径或null读取为空列表；格式错误或不支持的配置报错并保留原文件，不用空配置覆盖。随交付附带的 external-tools/SuperConnectX 便携目录及来源清单已按用户要求于 2026-10-27 删除；通用外部工具可继续手动登记其他本机 EXE。

Perfboard不嵌入、不自动启动或更新任何外部应用；没有驱动安装、串口连接或发送硬件数据流程。测试仅检查配置、状态、记录路由和无参数命令构造，不实际启动外部程序。

## 线径对照与参考电流

当前对照表覆盖4/0、3/0、2/0、1/0及AWG1至46，共50行。七列为AWG、裸导体直径mm、平方数mm²、国标常用平方参考mm²，以及保守/正常/最大参考电流A。表格在页面内部横向滚动，三档电流保留原表三位小数。

按[NBS/NIST Copper Wire Tables](https://nvlpubs.nist.gov/nistpubs/Legacy/hb/nbshandbook100.pdf)的AWG几何关系计算d_mm=0.127×92^((36−n)/39)、A_mm²=πd²/4；4/0、3/0、2/0、1/0的n依次为−3、−2、−1、0。直径为理想裸圆导体值，不能当作绝缘或绞线外径。公称面积采用0.5至400mm²的20项常用序列，按面积就近匹配，作为同一AWG行的规格对照，不再额外生成公称候选；小于0.5mm²显示“—”，不强配0.5。

三档电流直接保存自[原始对照表](https://www.liuwenhao.me/?p=5554)，抓取日期为2026-10-02，保存的HTML SHA256为78423cd66981653e019a1963774ef4b22f3ffa159002d416884b2a9ce18ca6f8；数值在src/tools/wire-gauge/current-reference.json，不根据J推导。原表未注明完整敷设、绝缘、环境和温升条件，页面保留短脚注“原表参考值，适用条件未注明”，换算依据放在折叠说明中。三档名称不代表经认证的安全载流保证。

期望电流支持A/mA，留空显示全部50行；非空必须为有限正数，零、负值、非法和溢出明确报错。按原表保守值≤期望电流≤最大值的闭区间选出匹配行，并保留上下相邻规格以便比较。行标签分别显示“参考区间内”“低于参考范围”“超过参考范围”；无区间匹配时明确显示无匹配，不把相邻规格当成命中。正常参考电流作为独立列保留，不作为新的过滤阈值。

旧初轮的64项AWG/公称候选、J上下限、I/J面积计算和向上公称匹配已由上述参考表替代；相关历史验收仅保留于CHANGELOG与VALIDATION。当前不增加长度、压降、温升、高频计算或额外条件输入，公称序列是数值参考子集，不是完整标准或合规认证。
