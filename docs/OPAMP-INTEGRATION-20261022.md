## 使用与范围

打开“硬件计算选型 → 运放选型计算”，左侧选择同相放大或差分放大，中间查看拓扑、结果和下方计算过程，右侧编辑参数。电阻值、单位、输入、基准、电源、摆幅余量和 GBW 修改后立即重算。点击拓扑电阻定位输入框；点击空白、按 Esc 或焦点离开参数区域取消高亮。输入无效时清除当前结果并暂停计算，避免显示旧结果。

全局搜索、侧边栏搜索和工作台支持“同相放大”“差分放大”“减法器”等名称，以及拼音和首字母；搜索结果直接选择对应电路。三个现有主题沿用相同 CSS 变量。工具无需连接资料仓库，也可在独立窗口打开；各窗口参数仅保存在该窗口会话内，不写入仓库，退出恢复示例。

中文参考为 TI [ZHCA755A](https://www.ti.com.cn/cn/lit/pdf/ZHCA755) 和 [ZHCA759A](https://www.ti.com.cn/cn/lit/pdf/ZHCA759)，拓扑按文档重新绘制。参考目录保留 38 个条目，包括同相/反相滞回比较器、窗口和过零检测；本轮仅两个计算器可用，其余标明待扩展。

## 模块组织与计算

前端全部位于 `src/tools/opamp/`，拆分元数据、纯计算、拓扑、公式、曲线、目录、链接、页面和样式；现有注册表、路由、统一搜索和窗口配置只增加模块入口。原生入口位于 `src-tauri/src/opamp/mod.rs`，仅允许主窗口及运放窗口打开本模块使用的 TI 中文 HTTPS 地址，不扩大通用外链权限。

同相增益为 `1 + R1/R2`。差分四个电阻独立可调，采用节点通用公式计算输出；电阻失配不会暗中调整其他阻值，只有“匹配比例”按钮根据 R1/R2/R3 调整 R4。展示差模、共模、基准增益和名义电阻 CMRR。带宽使用噪声增益，差分不误用差模增益。曲线的差分扫描固定共模电压。

公式假定理想运放在线性负反馈区。输出摆幅余量是可编辑假设，限幅曲线只作示意；器件输入共模、供电和输出超限分别提示。页面不是 SPICE 仿真，也未加入失调、容差、负载或稳定性模型。
