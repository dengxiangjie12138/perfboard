# TL431 符号与未接入模型修正（2026-10-22）

用户反馈 TL431 方框图和绕行 REF 导线不符合习惯，带上拉分压“悬空”结果也与截图中的仿真和 Mathcad 不一致。本次改为实际器件符号，并明确区分两种输入等效状态。

## TL431

原理图使用三端可调并联稳压器符号：上端 K 接输出，下端 A 接地，REF 从右侧水平直连 R1/R2 中点。K/A 与分压电阻走线保持正交，去掉符号外的方框和 REF 多余折线。符号参考 [TI TL431 规格书](https://www.ti.com.cn/cn/lit/gpn/TL431) 的简化电路与并联稳压应用图。计算公式和输入交互保持原有行为。

## 带上拉分压

截图将输入电压源设置为 0 V，电压源与 R1 支路仍然连接。在这个模型中 R1 仍向地分流，不能从方程分母删除 1/R1。默认“未接入”按该模型计算：

Vo = (Vpu/R3) / (1/R1 + 1/R2 + 1/R3)。

Vpu=3.3 V、R1=47 kΩ、R2=3 kΩ、R3=10 kΩ 得 **0.7258970359 V**，四舍五入为 **0.726 V**；流向 0 V 输入端的电流为 **15.44461778 µA**，对应截图的 15.4 µA。

如果输入端物理上真正开路，则输入支路电流为 0，这时才使用 Vo=Vpu·R2/(R2+R3)，结果约 **0.7615384615 V**。这两种边界条件不同。原版计算使用真正开路模型，却将它笼统标为用户所说的“悬空不接”，因此与用户的仿真模型不符。

界面新增“未接入时的输入等效”选项，默认 Vin=0 V、R1 支路保留；可显式选择“输入支路断开”。状态按钮、原理图输入标记、三态表格及公式同步切换；真正开路在图中显示断口。正接和反接的电压、电流保持同一模型计算，不受选项影响。
