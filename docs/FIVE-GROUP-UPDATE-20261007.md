## 五组变更

### 1. 变压器设计记录与工艺文件

增加独立变压器设计记录：设计号、工程 Rev、审核状态、磁芯与骨架快照、逻辑绕组、实际绕线工序、材料、装配说明、测试和尺寸分别保存。数据修订使用 CAS 校验，避免旧窗口覆盖新版本；历史保存完整快照，可只读查看或复制为新草稿。

支持裸设计 JSON 的导出和导入，以及旧 XLSX 设计表导入。导入先生成预览，显示工作表、行范围、原始单元格、结构化字段和警告，用户每次只确认一个方案；预览不会自动批量写入历史设计。选择磁芯后保存参数、来源、冲突说明及图片的冻结快照，已保存方案不随磁芯库后续变化被自动替换。

可导出中文工艺 PDF，包含绕线顺序、引脚与工序说明、冻结图片及待确认项。缺少绕组用途、同名端、绕向、观察视角、单位或测试条件时继续标为待确认。导入、保存和 PDF 导出都不会自动批准生产。

### 2. 物料页“显示立创仓库”

在“全部状态”之后增加 checkbox，默认关闭，并记住用户选择。关闭时，物料列表及本页搜索匹配、近似建议排除 `location.trim() === '立创仓库'` 的记录；勾选后包含这些记录。“立创仓库备用”等相似名称继续保留。

此选择仅影响物料页显示，不改库存记录、全局搜索或反馈电阻的库存候选规则。

### 3. 磁芯参考库与原图

已核验本机原始两份 Excel 的 SHA-256。磁芯手册整理为 **137 条具体记录、14 类形状、11 个独立图片资产和 12 个图片锚点**；保留原工作表、行号、单位、空值和来源。原有 137 条参数及来源继续保留，新旧来源差异和冲突可追溯，不以新资料静默改写旧设计的参数。

磁芯参考库与物料库存、变压器设计记录分开。手册数据整理不等于已将历史设计批量导入仓库，也不代表型号、材质、骨架或生产工艺已经核准。

### 4. 开发日志链接与保存状态

按实际安装的 Tiptap 链接 JSON 补齐 native 白名单：普通链接会自动带 `title:null`，粘贴的合法 `class` / `title` 字符串也按类型和长度校验。继续要求有效 HTTP(S) 目标，拒绝危险协议、凭据 URL、未知属性及错误类型；不删除链接或清理原文来绕过保存失败。

页面改名与正文保存使用统一保存状态。失败时保留草稿和修订号并显示错误，未保存的当前草稿不会沿用旧“已保存”提示；成功重试后才显示“已保存”，只清除对应保存错误，保留其它错误。已有 href-only 日志文档仍可读取。

### 5. 久坐提醒的恢复确认

休息期间，非软件注入标记的连续键鼠输入需持续满 **5 秒**才恢复工作，相邻操作间隔不得超过 **1 秒**；超过间隔重新确认，单次触碰不结束休息，确认期间继续计入休息。常见软件注入输入不参与确认，监测不可用时不自动确认恢复。

输入标记仅用于计时，不能认证操作者身份，也不能可靠区分虚拟 HID、驱动、部分远程或辅助工具输入。只处理标记与聚合时间，不记录键值、文字或鼠标轨迹。
