# 运放参数确认后生效修复 — 2026-10-22

用户发现输入电阻或电压的每个中间值都会参与计算，比较器因此可能提前翻转。例如基本比较器开启迟滞后，从 2.8 V 低态编辑为 2.5 V，输入过程中暂时出现的 2 V 会先触发高态，随后 2.5 V 位于迟滞区内，错误保留高态。

## 修改

图上浮层的数值与单位改为本地草稿，只有 Enter / 完成才一次提交。Esc、右上角取消、外点和切换电路都直接丢弃草稿，不写回旧值、不触碰状态记忆。校验只显示在编辑处；无效草稿禁止提交，原理图、公式、输出和曲线继续使用已生效参数。

右上角模型参数使用相同规则：Enter / 勾号提交，Esc / 取消 / 失焦丢弃。确认时只合并正在编辑的参数，保留当前其它参数及已生效逻辑状态。一次确认后才由页面计算并保留新的滞回状态。代码仍在 `src/tools/opamp/`，无新依赖、后端或数据库变更。
